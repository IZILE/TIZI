# TIZI 功能对照

这是实现与验证范围，不能把“配置可以导入”当作“真实节点已经连通”。Shadowrocket 官方介绍与更新记录包含隧道、DNS、规则、日志、脚本、HTTPS 解密、重写和 Tailscale 等功能；核对来源为 [App Store 的开发者说明](https://apps.apple.com/us/app/shadowrocket/id932747118)，核对日期 2026-10-11。

| 功能 | 当前状态 |
| --- | --- |
| 订阅、网址、分享链接、JSON、YAML、二维码导入导出 | 已实现；官网 Clash 节点与可转换规则、V2Ray/SS 文件、旧 WG 二维码均通过隔离应用流程检查 |
| 订阅折叠节点、用量、到期、自动更新 | 已实现；标题与节点保留单一操作选择，响应没有元数据时保持未知 |
| 添加／编辑节点、外露的移除按钮 | 已实现；共同对齐的参数表单，高级 JSON 连续展开并保留额外参数 |
| 操作选择与当前节点、右键菜单、撤销 | 单击选择、双击/Enter 执行，订阅整块选中；右键针对对象打开动画菜单，筛选/翻页后清除失效目标；单项移除可撤销 |
| 设置草稿、导入取消与配置恢复 | 草稿跨连接状态保留；准备阶段取消会停止提交，实际保存阶段暂时锁住取消；错误持续显示，配置保存前保留五份加密备份，并提供恢复入口 |
| 概览延迟数值与曲线 | 连接后数值默认约每15秒更新；曲线默认关闭，手动开启后默认每秒采集；节点批量测试独立 |
| 国家标记、TCP / UDP 标识、HTTP / TCP / ICMP 延迟 | 已实现；未连接时也可测试，HTTP 使用临时本地内核，延迟异步执行，保留页面操作 |
| 规则、全局、直连，域名 / CIDR / GeoIP | 已实现；独立策略组和自动故障切换待完成 |
| 本地代理、Windows 系统代理、TUN | 已接入；真实 TUN 网卡与指定测试地址的数据转发已有受控验证；系统代理有隔离流程检查 |
| TUN 栈、MTU、严格路由、DNS 接管、排除网段 | 已实现并由安装包内真实内核检查配置；指定目标的实际路由已实测，其他路由与环境仍需验证 |
| TCP 保活 / 并发、UDP 中继与超时、IPv6 | 已实现并检查配置；不同服务器的实际互通待验证 |
| DNS 模式、上游、bootstrap、代理域名解析、hosts | 已实现；支持内核可接受的 UDP / TCP / DoH / DoT / DoQ 地址 |
| 日志分类、容量与活动日志过期清理 | 已实现；上次连接诊断独立保存，完整 HTTP 请求日志待完成 |
| 托盘、登录启动、退出行为、连接状态恢复 | 已接入并通过隔离流程检查；重复托盘弹出位置已修复并有边界检查；原生多屏/DPI 与 UAC 需现场验证 |
| 连接 Logo、曲线、下拉菜单、窗口内更多页面 | 已实现并检查中间帧；展开与关闭均有连续形变；真实桌面帧率尚未量化 |
| 机场目录与联网搜索、最多 100 项缓存 | 已实现；独立搜索任务支持取消和重试，网络等待不锁住连接；每轮目标 15 个中文机场，按可比较月均价优先；仅归纳来源评价与排名，不提供自创质量评分 |
| SS、SSR、VMess、VLESS、Trojan、Hysteria / Hysteria2、TUIC、SOCKS / HTTP、WireGuard、AnyTLS、Snell、SSH、Mieru、Sudoku、MASQUE、TrustTunnel、GOST Relay | 已有对应配置入口；高级参数与不同服务的互通需逐项验证 |
| NaiveProxy、Juicity、OpenConnect、Brook、Lua | 待额外内核 / 运行时适配 |
| 按需连接、Tailscale、LAN 共享及认证、链式代理、独立策略组、协议嗅探 | 待完成桌面功能与交互，不能算已完整复刻 |
| HTTPS 解密、证书管理、URL 重写、脚本、模块、请求详情 | 待完成独立功能与兼容性验证 |
| 手机蜂窝数据、iOS 小组件、Siri / 快捷指令、苹果专属同步和系统权限项 | 不迁入 Windows；可对应的桌面功能另行设计 |

安装包附带代理内核、GeoIP、上游源码归档和第三方许可证。运行环境与构建说明见 BUILDING.md。
