# 订阅导入

在“文件 → 导入节点…”中粘贴订阅网址或导入命令，也可以使用“从剪贴板”和“从文件导入”。二维码图片使用同一套解析与保存流程。

支持直接 HTTP / HTTPS 订阅地址、`sub://` 编码订阅、`clash://install-config?url=…`、`shadowrocket://add/…` 及单条或数组形式的 Shadowrocket 订阅 JSON。订阅 JSON 的 `type` 使用 `Subscribe` / `subscription`，地址可在 `url` 或 `host`，名称可在 `remarks`、`name` 或 `title`。空白别名字段会继续使用后面的有效字段。

`.url` 文件也显示在导入文件筛选器中；Shadowrocket 导出的 `.url` 可直接包含一行 `sub://…`。以 `STATUS=` 和 `REMARKS=` 开头的订阅列表会把这些行视为说明，再读取后面的节点；标准 Base64 和 URL-safe Base64 均可识别。

`sub://` 和嵌套的 Shadowrocket 导入命令支持 `?remarks=名称`、`?name=名称` 或 `#名称`；名称参数与编码地址分别处理。Clash 导入命令的 `name` 参数也会填入添加窗口。订阅未指定名称时，程序依次读取响应的 `profile-title`、列表开头的 `REMARKS`、有效下载文件名和官网域名。只有默认的下载域名名称会在更新时补全，手动修改的名称会保留。

对于网站的便捷导入区：

- “复制 Clash 订阅链接”取得完整 Clash 配置。可转换的节点和规则会导入；策略组转换说明先显示在导入确认页。
- “复制 V2Ray + SS 订阅链接”和“复制 SS 订阅链接”取得相应的节点订阅，把复制内容粘贴到 TIZI 即可。
- 一键导入按钮调用相应的 Windows URL 协议。安装包会注册 `tizi`、`clash`、`shadowrocket` 和 `sub`，已有其他客户端的关联会保留。浏览器若询问是否打开应用，选择 TIZI 后仍需在程序中确认添加，不会自动连接或静默替换配置。
- 有些网站的 Shadowrocket 按钮会先提示在手机浏览器使用。这是网站自身的提示；也可使用它提供的订阅地址，通过 TIZI 的文本、剪贴板、文件或二维码入口导入。

重复导入同一个地址会更新原订阅，保留可匹配节点的身份和当前选择。订阅下载或解析失败时保持原有数据；配置继续使用 Windows 用户级加密保存。没有支持的连接节点时会报错，状态说明不会被当成节点。
