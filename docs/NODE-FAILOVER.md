在“设置 → 代理 → 自动切换节点”中启用“节点超时后自动切换同国家／地区节点”。此选项默认关闭，修改后立即保存。

启用且已连接时，程序每五秒检查当前节点能否通过配置的延迟测试网址。连续两次超时或被内核报告不可用后，才开始检查同国家／地区的其他节点。候选检测使用 HTTP 请求，最多四个同时进行；只在候选节点实际检测成功后切换。检测候选时不会改变当前选中节点、系统代理或 TUN 模式。

国家／地区按照节点的地区标注、国旗或名称识别。香港、台湾、澳门等地区分别匹配；无法识别当前地区、没有同地区候选，或候选全部检测失败时，保持当前节点。不会退到其他国家或地区。

一次失败不会立刻切换；恢复成功会清除连续失败计数。切换尝试之间保留三十秒间隔。手动选择节点、断开、关闭开关或退出时取消旧检测；提交切换前重新检查当前节点、设置及候选是否仍有效。自动切换成功后显示简短通知并记录日志。

检测正常表示能够通过所配置的测试网址，不代表所有网站都可访问。当前验证使用隔离合成数据与可取消的模拟探测，没有连接个人节点来验证真实环境中的切换。
