TIZI 在节点连接成功及切换节点后自动检测。检测只查询当前选中节点，不会切换系统代理、TUN 或当前路由模式。为避免分流规则把检测网址直连，检测临时使用仅绑定本机回环地址的单节点代理，完成、取消或退出后清理。不会执行机场搜索，也没有手动测试按钮。

默认来源为 [IPQuery](https://github.com/ipqwery/ipapi-py)、[Proxycheck v3](https://proxycheck.io/api/) 和 [RIPEstat RIR Stats Country](https://stat.ripe.net/docs/data-api/api-endpoints/rir-stats-country)。前两者提供风控参考分及网络信息，RIPEstat 提供 RIR 分配统计中的国家。查询会将所测出口 IP 交给这些来源；不会发送订阅地址、节点凭据或其他个人配置。可在“设置 → 诊断”关闭自动检测。

网络监控只显示网络类型与原生 IP 参考结果两个标签，不再显示风控分数或原始评分。网络类型只有在可用来源的分类一致时才显示，未知或分类冲突时隐藏。两个标签独立判断，一个结果未知不会隐藏另一个已知结果；断开连接后均隐藏。悬停或键盘聚焦可查看各自的数据来源、判定依据及查询时间。

原生 IP 是参考判断：RIR 分配国家与定位国家一致时显示“原生 IP”；明确不一致时显示“注册地不同”。定位国家来源冲突或缺少足够信息时不显示该标签。国家一致不能证明服务器物理位置、家庭用途或 IP 独享；“注册地不同”也不直接作为物理位置或用途的结论。

相同出口完整结果缓存十分钟，部分结果短暂缓存；收到 429 后按照 Retry-After 或 UTC 日界暂停该来源，不轮换地址重试限额。免费额度、数据内容与服务可用性可能变化；截至 2026-10-14，Proxycheck 无密钥额度为每日 100 次。IPQuery 无密钥提供公开免费接口，但同样可能限流。

“IP 检测服务”可填写自己的 Proxycheck 免费账户密钥和 ipapi.is 密钥，均存入当前用户的加密配置，使用 POST 请求体传递。ipapi.is 完整数据只作为额外交叉信息，其网络滥用比例不进入风控中位数。程序没有内置共享密钥。没有密钥时不调用 ipapi.is 的受限检测字段。

公开参考地址 8.8.8.8 的接口返回结构已单独检查；这不能代表个人节点的实际检测结果。隔离测试覆盖缺失、错误、限流、取消、冲突、缓存、密钥传输和局部检测配置，不替代用户真实网络环境验证。
