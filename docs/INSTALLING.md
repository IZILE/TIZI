TIZI 0.1.24 · Windows 10 2004 / Windows 11 x64

运行 TIZI-Setup.exe，选择安装目录，完成后使用桌面或开始菜单快捷方式打开。卸载保留个人配置。更新前请退出正在运行的 TIZI。

0.1.24：版本更新标题与设置卡片标题统一字重；节点切换时旧蓝底淡出、新蓝底淡入，文字和卡片保持稳定，快速反向切换从当前颜色继续。主窗口保留 Windows 原生最大化、还原动画所需的窗口装饰，同时沿用自绘标题栏。自动订阅更新的网络等待不再锁住内容区，短暂保存时合并最新配置，迟到响应不会恢复已移除的订阅或覆盖并发编辑。切出窗口时立即收回更多操作、下拉及右键菜单。

机场官网状态检查默认关闭，包括旧配置中原先默认启用的检查；只有在目录设置中重新主动勾选后才定时检查。此前“网站连接失败”来自官网 HEAD 访问检查，并不表示节点或 VPN 连接失败。手动检查的提示明确标为“官网访问检查”。AI 机场搜索仍只在手动搜索或重试时发起，不会因为启动、切换窗口或定时更新而调用 AI API。

0.1.23：一个订阅或手动导入分组只有 1–3 个节点时使用原来的横向列表，4 个及以上改为响应式宫格。节点卡片鼠标移入即显示蓝色边框，并在原灰色上叠加淡蓝色，移出后恢复；普通操作选择不再绘制灰色背景，当前节点继续使用蓝色实底，多选项目保留蓝色边框。自动订阅、目录和网站检查失败都只记录日志，手动更新失败仍通知。修改设置时不弹出未保存提醒，离开设置页且有未保存修改才显示黄色图标通知。未保存设置的退出确认不显示标题栏软件图标；从隐藏窗口发起退出会先显示确认窗口，再次打开时将确认窗口置前。已有管理员实例无法被普通启动器直接激活时，通过管理员激活助手重新显示同一个实例。

0.1.22：概览的下载、上传、延迟和本次已连接时长统一使用相同字号。默认窗口为 1032 × 722，订阅中的节点以响应式宫格展示，随窗口宽度改变列数；当前节点所在订阅默认展开。增加长按多选、批量移除、应用内版本更新和多厂商 AI API 设置。自动订阅更新失败只写入日志，手动更新失败才弹出通知。

0.1.21：机场选中背景恢复为与其他内容页相同的移动、伸缩动画，快速切换从当前显示位置继续；使用固定灰色选中背景，保持文字亮度与内容布局稳定。单击选择、双击详情、独立打开网站和空白取消选择继续生效。保留 0.1.20 的临时错误通知修复：订阅更新、机场目录更新、网站检查和机场搜索的失败统一显示在顶部通知栏，批量更新合并反馈，详细原因保留在日志。旧配置中的“连接失败”等临时文字不再出现在内容中，重启不会重放旧通知；可修正的表单校验和配置恢复提示仍保留在对应位置。搜索窗口打开时，错误从该窗口自己的通知栏显示，并保留重试入口。

0.1.19：概览将活动连接数量替换为“已连接时长”，只计算本次成功连接后的时间，断开清零，失败和取消不开始计时。断开时延迟为中性色“—”，迟到的结果不会将它染色。订阅与节点、分流规则、机场和实时连接页支持点击内容区域的空白处取消操作选择，不切换当前节点；移除、更新和网址等按钮仍可直接操作。移除常驻的双击/右键提示。机场卡片只使用一条背景过渡路径，重复点击不重新创建隐藏的详情布局。系统代理通过 Windows WinINet 接口设置并读取实际手动代理、自动发现和 PAC 状态；断开时仅恢复仍由 TIZI 持有的设置。

左侧原“连接记录”更名为“实时连接”：只显示当前经过 TIZI 的活动请求，未连接时为空，请求结束后会消失；它不是已保存的浏览历史。已连接时长独立于这个列表，切页和切换节点不会重新计时。

在“订阅与节点 → 导入节点”粘贴节点链接、订阅网址、Shadowrocket JSON、Clash YAML 或 .conf。“更多 → 文件 / 二维码”可选择配置文件和二维码图片，剪贴板也可导入文字或二维码。导入不会连接。包含不支持内容时先展示转换提示，取消会回到编辑器。重复订阅地址刷新原订阅，保留节点身份与选择；错误从当前窗口的通知栏显示。完整 Clash 订阅可导入节点及可转换规则，不会覆盖 TIZI 的端口、DNS 或 TUN 设置。

单击订阅标题选择整个订阅块，单击节点只选择操作对象；双击节点或按 Enter 才切换当前节点。订阅左侧箭头独立展开/收起，双击标题或按 Enter 也可展开/收起。订阅和节点操作选择互斥，实际当前节点使用与规则/全局按钮相同的蓝色背景，不再重复显示勾号；普通节点操作选择不再显示灰色填充；鼠标移入显示蓝色边框和淡蓝叠加，移出后恢复，多选节点保留蓝色边框。侧栏保持中性灰，规则/全局/直连、设置分区、日志筛选、复选框及普通菜单保持蓝色。节点、订阅、机场、规则和实时连接可右键打开带开合动画的对象菜单；正常点选通过右键菜单移除。长按内容项后选择“多选”或“全选”，红色移除按钮会从最后一个工具栏按钮右侧展开，取消选择后收回；Ctrl 单击、Shift 单击和 Ctrl+A 也可用于选择。移除后可撤销，整订阅移除前说明节点数量，连接中不能直接移除当前节点。筛选、翻页或项目消失后会清除失效选择。

“订阅网址”可查看或复制原地址，默认隐藏敏感部分；“更新”只更新该订阅。全部订阅的自动更新与间隔可从订阅右键菜单进入。自动订阅、目录和网站检查失败只记日志，不弹出通知；手动更新失败从通知栏反馈。“更多 → 导出”支持 JSON、YAML、可表示的分享链接、二维码和订阅地址，默认使用所选操作对象；选中一个订阅只默认导出该订阅。预览注明对象，复制和保存后显示结果，无有效输出时不能执行。导出包含节点凭据，请妥善保管。

节点页的“搜索本地节点”和机场页的“筛选已保存的机场”只筛选本机数据，不执行在线搜索或切换节点。设置草稿在切页、切语言和连接状态改变后继续保留；彻底退出时可返回编辑或明确放弃更改。导入准备期间取消会停止该次操作；短暂的实际保存阶段会等待保存完成再关闭，避免显示已取消但后台仍提交。日志复制完成后显示反馈，“清空当前类别”仅作用于当前日志筛选。

顶部按钮用图标表示状态：三条分开的直线组成播放三角形表示未连接，三段旋转弧线表示连接中，通过连接检查后形变为完整梯子；点击完整梯子可断开。连接中再次点击按钮可取消，托盘菜单同时提供“取消连接”。取消会停止正在等待的网络请求，清理本次内核并恢复本次取得的网络设置；清理期间显示“正在取消连接”，完成后可重新连接。主动取消不会显示成连接错误，也不会在下次启动时继续自动重试。连接异常时，梯子保持竖直，从中间逐渐出现锯齿裂痕，背景同步渐变为红色；点击可重试。悬停可查看错误原因。通知从窗口顶部滑入，默认约 6 秒后滑出，悬停会暂停收起，也可手动关闭。

菜单位于窗口最顶端，TIZI 字标、模式、节点与连接按钮共用一行及共同中线；字标可见高度约 29 像素，小于 36 像素的模式及代理控件，T 底部的两段方头横线与字体原横线同粗并对齐底边，顶栏两端相对下方内容面板等距。左侧导航沿用原有图案，选中时封闭部分渐进填白，切换时退回线框，保留文档、服务器及齿轮的镂空细节。节点栏居中显示国家、名称、订阅与协议，两行文字共用左边线。点击只能切换当前订阅中的节点；独立导入的节点没有无关候选项。模式控件位于内容面板的平直区域上方，窄窗口中自动分行。UDP 信息只显示一次。下拉栏从原控件连续延展为同宽面板，收起时连续返回控件；靠近窗口底部时向上展开。设置分区切换时卡片衔接位置及尺寸；“更多”从按钮原位连续延展为窗口内的圆角页面，关闭时回到原按钮；点击外部或按 Esc 可收起。表单文字、数值与下拉选项统一左对齐并保持相同留白，按钮与分段选项居中。

首次运行保持断开。默认开启“恢复上次连接状态”：退出时仍连接，下次启动会尝试恢复；手动断开后再退出，下次保持断开。旧版没有保存连接状态时按未连接处理。“常规”可关闭恢复，也可分别选择登录启动、隐藏登录启动以及关闭时退出或留在托盘。正常最小化保留任务栏入口，托盘菜单提供打开、连接和退出。

程序默认尝试以管理员身份启动。Windows 的 UAC 授权仍由系统决定；取消后可使用普通权限模式。TUN 需要管理员权限，选择的接管模式会保存；其他 VPN 正在使用默认路由时会提示先关闭其 TUN。程序先通过本地代理检查网页，成功后才启用系统代理或 TUN。“仅本地代理”不修改系统代理。“规则 / 全局 / 直连”在顶部选择。

概览只负责监控。未连接时隐藏图例、坐标和具体数据。连接后，蓝色曲线表示下载，绿色表示上传，黄色表示延迟；网速统一为 MB/S（每 MB 为 1,000,000 字节），延迟为 ms。图例可切换单条曲线，鼠标移到曲线上才出现时间和详细数值，提示浮在图内，不会挤动布局。流量是代理内核报告的数据。概览延迟数值默认约每 15 秒更新，延迟曲线默认关闭；点击图例中的“延迟”才开始高频曲线采集，再次点击停止并保留正常数值采样。每次连接都从曲线关闭状态开始。曲线默认每秒一次，上一请求未结束时不叠加，设置中可调整曲线间隔。失败与长间隔会断开曲线，不绘制孤立小点，不补造数值。节点列表的“测试延迟”与曲线采集分开，原有并发与超时设置保持。延迟结果按 ≤150 ms 绿色、151–300 ms 橙色、>300 ms 或失败红色显示；未测试显示灰色。“测试延迟”支持在未连接时测量：HTTP 测试临时启动仅监听本机的内核，不启用系统代理或 TUN，结束或取消后自动清理；TCP / ICMP 按所选节点测量。

添加与编辑节点共用清晰的参数表单，基础与协议字段对齐到同一列；高级 JSON 为默认收起的圆角展开区，未知的嵌套参数会保留，校验错误在页内持续显示并进入当前窗口通知栏。切换协议后再切回会保留该协议的参数、端口与未完成 JSON。导入准备期间可真正取消下载与解析；进入实际保存后暂时锁住取消，完成后才关闭窗口。

设置按常规、隧道、代理、TCP / UDP、DNS 和诊断分区。编辑过程中不弹出未保存通知；离开设置页且仍有修改时，才显示黄色图标提醒，返回编辑后收回。保存区持续显示“未保存更改”，保存结果同时从顶部通知栏显示。切换分区、页面、语言，以及连接状态变化时会保留当前草稿；语言选择立即生效。连接中本地端口和出口网卡动态禁用，保存层也会拒绝在连接中改变这两项。诊断显示真实已加载的订阅、节点和规则数量，并提供加密数据恢复入口。读取失败保留持续恢复提示，不显示成首次使用空列表。每次替换配置前保留最多五份加密备份；从备份恢复会合并缺失内容并保留当前设置及已有项目，不自动连接。日志页面区分全部、代理、DNS、应用，日志设置可选择记录、保存、保留天数和数量。订阅更新、机场目录与日志选项分别放在所属页面。实际内核原始消息可能保留协议名和技术字段。

机场导航的“搜索最新”复用已保存的预算、地区、协议、试用和搜索模式。每轮目标 15 个中文机场，资料不足可以少返回；按所选币种的可比较月均价格优先排序，旧结果继续保留，按网址去重，最多 100 项，超出时淘汰最旧项。搜索有独立进度、取消和失败重试，网络等待不锁住连接操作；重复点击同一进行中的搜索不会新增 API 请求。失败与取消保留原缓存，返回结果合并到最新状态，保留期间的编辑。单击卡片只选择，双击或 Enter 打开详情；详情将套餐、实际支付金额、流量及条件分区排列，评价和官网来源可展开。“打开网站”仅打开机场公开网站，取得个人订阅后需在节点页导入。

搜索综合可追溯的使用者评价和既有排名，展示来源、日期及原榜单名次，不自行实测安全性或 IP 质量，不生成安全认证或自创评分。价格标明币种、周期和单位，资料不明确时保持未知。“更多 → 联网搜索设置”支持 OpenAI、DeepSeek、通义千问、Kimi、智谱、Claude、Gemini 和自定义 API。可选择 OpenAI Responses、OpenAI 兼容 Chat、Claude Messages 或 Gemini GenerateContent 协议，并修改地址和模型。切换厂商时分别保存密钥；没有原生联网搜索的协议会先收集公开网页来源再交给模型整理，只采用实际获取的来源。API 密钥仅在当前 Windows 用户的加密配置中保存；搜索不发送个人节点或订阅密钥。兼容请求与响应通过合成检查，真实厂商账号和所有模型尚未逐一调用验证。

“设置 → 常规 → 检查更新”及“帮助 → 检查更新”可读取 GitHub 最新正式版本。发现新版本后显示更新说明，手动选择下载安装；下载可取消。安装包必须来自 IZILE/TIZI 的 GitHub Release 并通过 SHA-256 校验，之后程序正常退出并安装，保留加密配置。检查不会在启动时自动发起。

“导入机场列表”支持目录网址或 JSON。格式为 {"version":1,"providers":[{"name":"示例","url":"https://example.com","region":"示例"}]}。目录更新不会删除其他来源的搜索缓存。

“规则 → 导入规则”支持 Clash YAML / JSON 和常见规则文本，包括 GEOIP、IPv4 / IPv6 CIDR、no-resolve 和末尾 MATCH。单击规则只选择，双击、Enter 或右键菜单编辑类型、内容、执行动作和 no-resolve 选项；保存时在原位置替换，校验失败保留编辑窗口。无有效选择时移动和移除按钮禁用。规则页支持即时搜索与一键清空，节点页提供独立的本地节点筛选。外部 select 组按第一个默认选项转换，独立策略组选点尚未实现。导入会合并去重，保留手动规则；不会自动删除上游撤回的旧规则。规则模式才使用这些分流规则。连接记录在窄窗口也可通过双击、Enter 或右键查看详情，记录消失后不能继续关闭旧目标。

协议支持与尚未完成的功能见 FEATURES.md。界面和交互检查使用隔离的合成数据；不同服务、系统代理与 TUN 的可用性仍取决于实际网络环境。
