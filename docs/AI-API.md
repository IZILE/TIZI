接口协议表示请求和响应的格式。设置页会按所选厂商列出已实现的格式，并在切换格式时同步默认接口地址；手动填写的网关地址会保留。每家厂商的密钥与设置草稿分别保存，密钥存入本机加密配置。已保存的模型选择在仍符合可用列表与筛选规则时保留。

“搜索模型”使用与其他下拉栏相同的整栏点击选择，不提供手动输入。打开设置窗口后，程序自动从当前厂商接口读取模型列表，不发起模型推理。切换厂商时恢复各自的列表并自动刷新；修改密钥、地址或协议会清除旧列表，结束编辑后重新获取。厂商和模型再次展开时，当前选项滚到列表顶端，原有顺序不变。

列表只展示适合网页资料整理的较新通用文本系列，排除语音、实时音频、图片或视频生成、嵌入、重排、审核和其他专用模型。同一系列保留较新的版本，日期快照优先合并为无日期别名；每家厂商最多显示十二项。规则按接口返回的名称和停用标志收敛，不会凭空添加账号未返回的模型；已有选择只有在仍符合筛选规则时保留。接口不提供模型列表或获取失败时，保留可用缓存。没有合适选项时需要重新获取并选择，不能输入任意名称。自定义网关的未知别名仅按用途及快照去重，不推断未提供的生命周期信息。

当前实现包括 Responses API、兼容的 Chat Completions、Anthropic Messages 和 Gemini GenerateContent。自定义网关可选择全部四种格式。DeepSeek 提供 Chat、Responses 与 Messages 三种选择，具体支持范围以[官方文档](https://api-docs.deepseek.com/)、[Responses 说明](https://api-docs.deepseek.com/guides/responses_api/)及 [Anthropic 兼容说明](https://api-docs.deepseek.com/guides/anthropic_api/)为依据。

不同厂商采用相同格式，不代表具备相同的搜索工具。OpenAI 官方 Responses 接口使用原有搜索流程；其他已适配接口使用独立收集的公开网页证据，再交给模型整理。DeepSeek Responses 不请求其忽略的内置 web_search 工具，返回结果仍需通过实际网页证据校验。普通节点连接不会触发机场搜索；网站与 AI 检索由对应功能的明确操作触发。

兼容接口的网页检索使用简短的中文主题词，过滤无关结果，并补读官网和价格、客户端说明页面。单个页面从域名解析到正文读取共用超时；慢页面可以跳过。机场搜索默认使用此设置页当前选择的厂商及其地址、模型和密钥。

兼容性检查使用隔离的模拟 HTTP 响应，覆盖请求地址、认证头、四类响应解析及证据校验，没有读取个人 API 密钥，也没有调用真实收费接口。第三方模型、配额与能力会变化；如果已有自定义网关，请按照该网关的文档填写完整接口地址，再从获取的列表中选择模型。
